# Percobaan 1: Akuisisi Sensor

Dokumentasi ini memuat detail pelaksanaan Percobaan 1 mengenai pembacaan sensor DHT11 menggunakan mikrokontroler ESP8266. 

## Tujuan
Memahami dan mengimplementasikan proses akuisisi data sensor suhu dan kelembaban menggunakan sensor DHT22 pada ESP8266.

## Spesifikasi yang Diharapkan
1. ESP8266 berhasil membaca data suhu dan kelembaban dari sensor DHT22
2. Data suhu dan kelembaban ditampilkan pada Serial Monitor setiap 2 detik
3. Program dapat mendeteksi dan menampilkan peringatan apabila pembacaan sensor gagal (nilai NaN).
4. Tidak terjadi error saat proses kompilasi maupun pembacaan sensor

## Langkah Percobaan
1. Persiapkan alat dan bahan
2. Konfigurasi rangkaian
3. Compile dan Upload Program
