# Percobaan 2: Kendali Aktuator

Dokumentasi ini memuat detail pelaksanaan Percobaan 1 mengenai implementasi 

## Tujuan
1. Fokus percobaan adalah memahami dan mengimplementasikan kendali aktuator (relay) secara otomatis berdasarkan data suhu yang diakuisisi dari sensor DHT22

## Spesifikasi yang Diharapkan
1. Relay (disimulasikan dengan LED) menyala ketika suhu terbaca melebihi ambang batas (threshold) yang ditentukan
2. Relay mati kembali ketika suhu turun di bawah ambang batas
3. Serial Monitor menampilkan data suhu dan status aktuator (ON/OFF) secara bersamaan.
4. Pola menyala-mati aktuator berjalan konsisten sesuai kondisi suhu, tanpa error

## Langkah Percobaan
1. Persiapkan alat dan bahan
2. Konfigurasi rangkaian
3. Compile dan Upload Program
